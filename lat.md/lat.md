# browser.jr knowledge graph

This graph maps the implemented browser.jr architecture, its durable design decisions, and the domain concepts that connect code paths.

- [[architecture]] describes runtime flow and module ownership.
- [[decisions]] records choices that constrain future changes.
- [[domain]] connects the project vocabulary to state and invariants in code.

The user-facing product contract remains in the repository [README](../README.md). The [glossary](../glossary.md) owns shared definitions, and the [architecture draft](../architecture.md) also contains proposed designs that are not all implemented.
